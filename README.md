More and more websites contain video and automatically start playing these videos without user consent. 
Chrome removed a setting that disabled auto-play. 

A lot of these videos are bandwidth and CPU intensive, they drain the network and the computer battery, and make everything slower in the page. 
This simple extension detects video playback elements on the page and pauses them unless the user has clicked on the element. It supports iFrames and shadow-doms. 

The extension keeps a list of the websites where it has detected video automatically playing, and lets the user disable the extension for specific sites.
